# @wblxr408/messy-etl-runtime（脏文档与复杂表格结构化 ETL 插件）

[English](README.md)

面向现场财务对账、采购核单与扫描单据提取的脏数据结构化 ETL 插件：支持前导行跳过、合并单元格继承标记、合计行拆分、金额精确到分、置信度标红及人工修正确认提交。

## 升级并打开核对台

1. 有经过审阅的 `1.0.2` 发布来源后，使用 AGH 的托管包更新流程，从该来源升级 `@wblxr408/messy-etl-runtime`。仅更新插件不会启用原生核对台。
2. 在 **设置 → 应用** 中预览运行包版本为 `1.0.2` 的应用。该应用沿用 AGH 默认品牌，请确认预览中列出了 **非标单据核对台** 导航入口。
3. 如果当前配置档案已采用其他应用，采用此应用会替换原有应用。选择采用可添加核对台入口，同时保留 AGH 默认的导航和对话界面。
4. 从导航打开 **非标单据核对台**，也可继续使用原有的 `?page=messy-etl-review` 链接。已有的 ETL 批次仍可访问。

如需撤销对原生核对台的访问，请在 **设置 → 应用** 中选择 **恢复官方界面**。此操作不会卸载插件，也不会删除 ETL 批次数据。
